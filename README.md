# 🎮 Tic Tac Toe Game – Java

## 📌 About the Project
Tic Tac Toe is a console-based two-player game developed using Java. The game is played on a 3×3 board where two players take turns placing their symbols, **X** and **O**.

The player who successfully places three identical symbols in a horizontal, vertical, or diagonal line wins the game. If all cells are filled without a winner, the match ends in a draw.

## 🛠️ Technologies Used
- Java
- Scanner Class
- 2D Arrays
- Loops
- Conditional Statements
- Methods

## ✨ Features
- Two-player gameplay.
- 3×3 game board.
- Player 1 uses X and Player 2 uses O.
- Interactive console-based input.
- Validates row and column positions.
- Prevents players from selecting occupied cells.
- Checks all winning conditions:
  - Horizontal rows
  - Vertical columns
  - Diagonal
  - Reverse diagonal
- Detects a draw when the board is full.
- Displays the winner or draw result.

## 🎯 How to Play
1. Run the Java program.
2. Player 1 starts with X.
3. Player 2 plays with O.
4. Enter the row number between 0 and 2.
5. Enter the column number between 0 and 2.
6. Players take turns placing their symbols.
7. The first player to get three matching symbols in a row wins.
8. If the board is full and nobody wins, the match ends in a draw.

## 💻 How to Run

**1. Clone the repository**

```bash
git clone https://github.com/chandu-915/ConsoleBasedApps.git
```

**2. Navigate to the project folder**

```bash
cd ConsoleBasedApps
```

**3. Compile the Java program**

```bash
javac -d . TicTacToe.java
```

**4. Run the program**

```bash
java com.consolebasedapp.TicTacToe
```
